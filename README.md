# iPhone Stats Display for Arduino UNO R4 WiFi

A small desk display that shows live stats from your iPhone on an OLED screen driven by an **Arduino UNO R4 WiFi**. A companion iOS app collects your data and sends it to the Arduino over **Bluetooth Low Energy (BLE)**.

The screen shows:

- **Current time**, kept by the Arduino's built-in real-time clock
- **iPhone battery level** with a battery icon and charging indicator
- **Today's step count** from Apple Health
- **Your next calendar event**: when it starts and its title

```
┌──────────────────────────────┐
│ 14:32  ●           +87% [███]│
├──────────────────────────────┤
│ 8 432 pas                    │
├──────────────────────────────┤
│ Auj. 15:00                   │
│ Réunion projet               │
└──────────────────────────────┘
```

## Hardware

- Arduino UNO R4 WiFi
- 0.96" OLED display, **128×64, I2C, SSD1306** (4 pins: GND, VCC, SCL, SDA)
  - A 1.3" SH1106 128×64 display also works (see configuration)
  - 0.91" 128×32 displays are **not** supported by the layout
- 4 male-to-female jumper wires
- An iPhone running iOS 17 or later

### Wiring

| OLED | Arduino UNO R4 WiFi |
|---|---|
| GND | GND |
| VCC | 3.3V |
| SCL | SCL (top-left header, next to AREF) |
| SDA | SDA |

The SCL and SDA header pins are internally connected to A5 and A4, so either pair works.

## Arduino setup

1. Install the [Arduino IDE](https://www.arduino.cc/en/software) 2.x.
2. Install the **Arduino UNO R4 Boards** package (Tools → Board → Boards Manager).
3. Install these libraries (Tools → Manage Libraries):
   - `ArduinoBLE`
   - `U8g2`
4. Open `arduino/ecran_stats/ecran_stats.ino`.
5. If you use a 1.3" SH1106 display, set `ECRAN_SH1106` to `1` at the top of the sketch.
6. Select **Arduino UNO R4 WiFi** and upload.

The display shows "En attente de l'iPhone..." until the app connects.

## iOS setup

The repository contains the Swift source files only. To build the app:

1. In Xcode, choose **File → New → Project → iOS → App**. Use **SwiftUI** for the interface and **Swift** as the language.
2. Delete the `...App.swift` and `ContentView.swift` files generated by Xcode. Both are replaced by `EcranStatsApp.swift`.
3. Drag the three files from `ios/EcranStats/` into the project, with **Copy items if needed** checked.
4. Set the deployment target to **iOS 17.0** or later.
5. In **Signing & Capabilities**, select your team and add the **HealthKit** capability.
6. In the **Info** tab, add these keys, each with a non-empty description:

   | Key | Example value |
   |---|---|
   | `NSBluetoothAlwaysUsageDescription` | To send your stats to the Arduino display. |
   | `NSHealthShareUsageDescription` | To show today's step count on the display. |
   | `NSCalendarsFullAccessUsageDescription` | To show your next event on the display. |

7. Run the app on a **physical iPhone**. The simulator has no Bluetooth, so it cannot connect to the Arduino.

On first launch, accept the Bluetooth, Health and Calendar permissions. The app finds the Arduino automatically, and the status dot turns green once connected.

## How it works

The Arduino advertises a custom BLE service. The iOS app scans for it, connects, and writes values to five characteristics as soon as the connection is ready, then once a minute while the app is open.

| Characteristic | UUID | Format |
|---|---|---|
| Local time | `7A1E0001-4B5C-4F6D-9E8A-1B2C3D4E5F60` | `UInt32` little-endian, Unix time + time zone offset |
| Battery | `7A1E0002-4B5C-4F6D-9E8A-1B2C3D4E5F60` | 2 bytes: level 0–100 (255 = unknown), charging 0/1 |
| Steps | `7A1E0003-4B5C-4F6D-9E8A-1B2C3D4E5F60` | `UInt32` little-endian (`0xFFFFFFFF` = unknown) |
| Event time | `7A1E0004-4B5C-4F6D-9E8A-1B2C3D4E5F60` | UTF-8 string, max 20 bytes |
| Event title | `7A1E0005-4B5C-4F6D-9E8A-1B2C3D4E5F60` | UTF-8 string, max 20 bytes |

Service UUID: `7A1E0000-4B5C-4F6D-9E8A-1B2C3D4E5F60`

The Arduino stores the received time in its real-time clock, so the clock keeps running after the app is closed. Text values are truncated on the iPhone to 20 bytes, the size of a basic BLE write, without splitting accented characters.

## Limitations

- **Updates only while the app is open.** Once closed, the display keeps the last values received, and the clock keeps running.
- **Long event titles are truncated** to about 20 characters.
- **All-day events are skipped**; the app shows the next timed event within the next 7 days.

## Troubleshooting

| Problem | Fix |
|---|---|
| Black screen on launch, crash mentioning a usage description | One of the three `Info` keys is missing or empty. |
| `Type 'BLEManager' does not conform to protocol 'ObservableObject'` | Make sure `import Combine` is present at the top of `BLEManager.swift` and `StatsCollector.swift`. |
| `Device ... isn't registered in your developer account` | The run destination is your Mac. Select your iPhone in the device menu at the top of Xcode. |
| `Build input file cannot be found: ...Bridging-Header.h` | In Build Settings, search `bridging` and clear the **Bridging Header** value. |
| The app stays on "Recherche de l'Arduino…" | Check that the sketch is uploaded and the board is powered. Bluetooth must be enabled on the iPhone. |
| The OLED stays black | Check the wiring. If you have a 1.3" display, set `ECRAN_SH1106` to `1`. |
